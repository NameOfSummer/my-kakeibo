# 取り込んだ取引にカードと店名を持たせるが、支払方法は作らない

カードの利用明細 CSV から支出の取引を取り込めるようにする。重複して取り込むのを防ぐため、また一覧で取り込み元がわかるように、取り込んだ取引にはカード（取り込み元）と店名を持たせる。ただしカードは「どう払ったか」の記録ではないので、手入力の取引では選べず、編集もできない。複製した取引にも引き継がない。支払方法（現金・各カードを選んで記録する機能）は引き続き作らない。

## Considered Options

- **カードを支払方法として扱う**（手入力でも現金や各カードを選べる）: 入力の手間が増え、検索の条件も増える。家計簿の目的（月ごとの振り返り）にとって必要がないので採らなかった。
- **店名をメモに入れる**: 保存する項目は増えないが、メモを直すと重複の判定から外れてしまうので採らなかった。

## Consequences

- 取引の保存の形が変わるため、`DB_VERSION` と `BACKUP_VERSION` を上げる。店名ルールも保存とバックアップの対象になる。
- カードは CSV の形式ごとに固定の 3 つ（楽天カード、リクルートカード、ビックカメラSuicaカード）とし、初期費目と同じく固定の id を持つ。同じ会社のカードを 2 枚持っても区別しない。
