# データはブラウザ内にだけ保存し、端末間同期はしない

利用者は自分ひとりで、入力は PC 1 台から行う。そのためサーバーや BaaS は持たず、取引と費目はブラウザ内（IndexedDB）にだけ保存する。サーバーの運用・認証・個人情報の外部保管が不要になる代わりに、端末間の同期はできず、ブラウザのデータ消去や PC の故障でデータが消える。消失への対策は JSON の書き出しと読み込み（確認したうえで全件置き換え）で行う。

## Consequences

- スマホからの入力や複数端末での利用が必要になったら、この決定を見直す（保存先の移行が必要になる）。
- バックアップを取るかどうかは利用者に任される。アプリは自動バックアップをしない。
