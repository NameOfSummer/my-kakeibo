# 家計簿

自分ひとりのお金の出入りを記録し、月ごとに振り返るための家計簿です。データはブラウザの中（IndexedDB）にだけ保存し、外部には送りません。

## できること

- 支出・収入の取引を追加・編集・複製・削除する（削除の前に確認を出す）
- 月ごとに、取引の一覧・支出合計・収入合計・収支差・費目ごとの内訳を見る
- 開いている月までの直近 12 か月の推移を表で見る
- キーワード・金額の範囲・種別と費目・期間で取引を検索する
- 費目を追加・名前変更し、使わなくなった費目を非表示にする
- 取引と費目をまとめて JSON に書き出し、読み込んで置き換える

## 導入方法

インストールは不要です。ブラウザで次の URL を開きます。

https://nameofsummer.github.io/my-kakeibo/

### 手元で動かす

Node.js 26 以上が必要です。

```bash
npm ci
npm run dev
```

表示された URL をブラウザで開きます。

## 使い方

1. 右上の **取引を追加** を押し、種別・日付・金額・費目（とメモ）を入れて保存する
2. **月** のタブで、その月の合計と一覧を見る。矢印や月の選択で月を切り替える
3. 一覧の各行のボタンで、編集・複製（日付を今日にした入力画面を開く）・削除ができる

### 金額の入れ方

- 円の整数で入れます。カンマや全角数字も使えます。
- 返品による返金などの取り消しは、マイナスの支出（例: `-1200`）として入れます。

### 費目

- **費目** のタブで、支出用と収入用の費目を追加・名前変更できます。同じ種別の中で名前は重複できません。
- 費目は削除できず、非表示にします。非表示の費目は新しい取引では選べませんが、過去の取引と集計には残ります。再表示もできます。

### 検索

- 指定した条件をすべて満たす取引を出します。
- キーワードはメモと費目名に部分一致で当て、全角と半角、大文字と小文字は区別しません。
- 金額は入れた値のまま比べます（-3,000 円の支出は「-5,000〜-1,000」で見つかり、「1,000〜5,000」では見つかりません）。

### カードの取り込み

- **取り込み** のタブで、カード会社のサイトから落とした利用明細の CSV を選ぶと、支出の取引としてまとめて登録できます（今はリクルートカードに対応）。
- 取り込む前に一覧で確認し、明細ごとに費目を変えられます。取引の日付は利用日です。確定していない明細は取り込みません。
- カード・利用日・店名・金額が同じ取引をすでに持っていれば、その件数ぶんは飛ばします（同じ CSV を 2 回選んでも二重に入りません）。
- **店名ルール**（店名にこの語を含めばこの費目）で、取り込むときの費目を決めます。当たらなければ「その他」になります。

## データとバックアップ

- データはこのブラウザの中にだけあります。別のブラウザや PC とは同期しません。
- ブラウザのサイトデータを消すと、データも消えます。**バックアップ** のタブから JSON を書き出して保存してください（自動バックアップはしません）。
- 読み込むと、今のデータはすべてファイルの内容に置き換わります（追加はしません）。店名ルールもバックアップに含まれます。
